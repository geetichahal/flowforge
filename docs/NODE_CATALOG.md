# Node catalog

Mapping status: **direct** = native equivalent; **approximate** = built from a general node (e.g. HTTP call to an incoming webhook, an Agent with a tool, a Custom Function); **none** = no equivalent: the step is reported as `W_FLOWISE_UNSUPPORTED`, shown as a sticky note on the Flowise canvas, and still performed by the n8n and Python outputs.
