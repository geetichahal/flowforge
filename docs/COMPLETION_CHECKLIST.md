Status as of 2026-11-24. "Complete" means the underlying function was exercised by a test or a recorded
run, not just that a UI exists. Each test named below is in `tests/test_flowforge.py` (50 tests, all passing:
`.venv/bin/python -m pytest -q`). Evidence files are in `docs/evidence/` and `eval/`.

## How to re-run every check

```bash
.venv/bin/python -m pytest -q                                              # 50 unit/integration tests
.venv/bin/python -m flowforge eval --mode template                         # + --requests eval/requests-heldout2.json
.venv/bin/python -m flowforge eval --mode llm --requests eval/requests-heldout2.json   # needs Ollama
.venv/bin/python tools/api_smoke.py                                        # FastAPI over HTTP
.venv/bin/python tools/flowise_demo.py                                     # needs Flowise + API key
.venv/bin/python tools/flowise_import_all.py                               # needs Flowise + API key
N8N_DIR=/path/to/n8n-install .venv/bin/python tools/n8n_check.py           # needs `npm install n8n`
.venv/bin/python tools/catalog_doc.py                                      # regenerates docs/NODE_CATALOG.md
```
