# FlowForge server

Natural-language automations, generated as a Flowise flow, an n8n workflow and a Python script,
validated, self-corrected and dry-run. This Space runs the FastAPI backend and the website, with a
local LLM planner (Ollama, `qwen3:4b`) on CPU.

Source, docs and evaluation: https://github.com/geetichahal/flowforge ·
Static website: https://geetichahal.github.io/flowforge/

This Space is deployed automatically from the GitHub repository; edit the code there.
